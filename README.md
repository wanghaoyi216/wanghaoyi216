## 🧭 关于我

我是中国地质大学（武汉）地理科学与信息工程学院的硕士在读。做的事情比较杂，但主线很清晰：**用 AI 和工程能力，去解决具体领域里那些「没人愿意写但确实很烦」的问题**——比如导师明天就要的汇报 PPT、课程平台的重复劳动、读研两年攒下的笔记散落各处。

我不喜欢只写 demo。所以我给自己的项目定了两条规矩：**能跑**、**能验收**。仓库里能看到的东西，都是我自己每天在用的。

- 🔭 **最近在折腾**：科研汇报自动成稿 + 排版自动验收（把四道质量闸门写进代码，而不是靠肉眼检查）
- 🌱 **正在补**：TypeScript / 现代前端工程化，以及把 GIS 能力接进大模型工具链
- 🧩 **找合作**：欢迎遥感、地理信息、教育信息化方向的朋友交流；也欢迎来提 issue 或 PR
- 💬 **可以问我**：Python 数据处理、Spring Cloud 微服务、Vue3、PPT/文档自动化
- 📫 **联系我**：haoyiwang156@gmail.com
